Haplina Naxx Parse Playbook — Alliance-Normalized v2

The overall top-five dataset is 84% Alliance, so most conclusions survive intact. The major correction is how we value melee weaving and how we choose the comparison player when Horde racials/Windfury are present.

Big correction: Smcadogx's Patchwerk rank-1 is Orc + actual Windfury. It remains useful as a Horde ceiling example, but it is no longer the Haplina melee benchmark. The Alliance weave benchmark is Charies / Andrenn / Xal: 6–9 Raptor Strikes, essentially no white-melee package.

What changed globally

  • Unchanged: 20/31/0, DMF Damage, Slavemaker/PvP-glove meta, pet problem, Aimed utilization, engineering, kill-time conclusions, Gothik padding and KT utility-duty diagnosis. Renataki remains valuable, but boss-specific; it is no longer the default Alliance Patchwerk recommendation.
  • Patchwerk: weaving stays, but as late-stage Alliance Raptor-only optimization. Pure-ranged Xert (Alliance) at 1347 DPS is your first model.
  • Grobbulus: weaving is now a NO for Haplina; the meaningful top-five weaver is the Orc+WF log.
  • Thaddius: heavy weaving is downgraded to opportunistic only for Alliance.
  • Pet: compare against Alliance medians. Patchwerk median changes only from ~174 to ~167 DPS, so the original conclusion remains very strong.
  • Shot cadence: same-faction rates replace all-faction rates. They are usually nearly identical; Horde was not secretly inflating the whole dataset.
  • Leaderboard: overall #1 is Horde on Patchwerk, Grobbulus, Anub, Maexxna and Sapphiron, so the playbook now shows a same-faction benchmark separately.
