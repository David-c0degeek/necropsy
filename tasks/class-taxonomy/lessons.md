# Lessons

- WCL metadata already provides display name and API slug; keep both. JSON-scalar errors must not be treated as empty ranking lists.

- Empty-selection sentinels can change across UI library versions; run the actual identify/select/stop/reload flow. Textual uses Select.NULL.
- Three-tree totals are not individual talent allocations. Equal totals cannot certify identical builds, and tied maxima cannot establish a single primary tree.
- Use explicit UTF-8 for Windows research/edit scripts; default decoding can corrupt typographic text even while Python remains parseable. Lint and diff checks caught and corrected this before commit.
