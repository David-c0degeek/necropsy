## Pre-mortem guardrails

- **PM-57 — High — owned events disappear.** Evidence: the 435-fight raw audit finds four counterexamples to friendlyPets-only filtering. Use the transitively owned report-catalog AND fight units; reject ambiguous/conflicting/cyclic identities. Keep requested source streams when ownership is incomplete or projection is unsupported. Prefer existing verified requested streams on resume. Verify independent raw equality including event order, duplicates and the four residual witnesses.
- **PM-58 — High — future hit types silently lose critical damage.** Evidence: the empirical critical rule matches all 435 sampled fights, not an unlimited server guarantee. Bind a named versioned rule to an explicit known hit-type domain; fall back to the API for missing, mistyped or unknown damage hit types. Reader must refuse claiming a derived critical stream when this guard fails.
- **PM-59 — High — fabricated provenance passes archive verification.** Evidence: v3 accepts only byte-identical derived targets. Introduce v4 explicitly; derived records have no request identity or costs, name one exact unfiltered parent, bind its complete page chain and certify the exact ordered projection. Check every generated byte after hashing, even if an attacker updates the child digest. Preserve old formats/readers and update raw/freezer entry points. Parent report/revision/fight/endpoint/options and ownership evidence must all bind to the original acquisition.

Implementation: common projection contract; acquisition with cache-first/fallback; v4 writer and strict reader; raw/freezer support; synthetic adversarial and independent corpus tests; full static/fast/golden/browser verification. No v3 reinterpretation, fabricated API responses, rewritten old cache pages, or automatic content acceptance.

## Guardrail outcomes

- **PM-57 — Prevented prediction.** The report/fight transitive graph retains catalog-only owned events; incomplete ownership and corrupt requested cache cases are explicit regression tests. The independent verifier now checks the original fight's owner/type completeness itself, even if a forged marker claims completeness and rebinds the original report hash. Physical fight reuse does not change comparison eligibility.
- **PM-58 — Prevented prediction, with a verification correction.** Unknown/missing/mistyped damage hit types take the original requested path and cannot be relabeled as a certified derivation. Recorded input exposed an overly narrow initial domain (known non-critical hit type 15); this initially reduced optimization eligibility rather than losing events. The named rule now includes that witnessed value, with a retained regression. Future unknown values still fall back.
- **PM-59 — Prevented prediction.** V4 reader and independent raw verifier reject wrong actor sets/rules, mismatched parent revision/endpoint/digests, invented costs, dual request/derived identities, downgraded format, missing original/parent members and changed or reordered child bytes even with recomputed hashes. Old requested scopes and formats retain their original interpretation. Released 0.7.1 consumer compatibility remains an explicit rollout constraint.
- **Additional observed assumption:** real report catalogs contain the unowned Environment sentinel -1. The first conservative graph guard rejected it, causing requested-stream fallback. It now permits that unowned sentinel while keeping projected actor IDs positive; a unit regression covers the case. No registered capture was modified to accommodate the implementation.
